## 📌 Sobre o Projeto

Este projeto consiste no desenvolvimento e recriação autônoma de uma **Landing Page**, aplicando na prática conceitos fundamentais de desenvolvimento Front-End semântico, estilização e fidelidade visual a partir de um protótipo de design.

O objetivo principal deste repositório é servir como **vitrine técnica**, demonstrando a capacidade de extrair requisitos visuais de um design no Figma e traduzi-los em código limpo e organizado.

### 🎯 Objetivos de Aprendizado
- 📐 **Leitura e Interpretação de Design:** Analisar o protótipo no Figma para extrair cores, tipografia, espaçamentos e hierarquia visual.
- 🏗️ **HTML5 Semântico:** Estruturar a página utilizando as melhores práticas para acessibilidade e SEO.
- 🎨 **CSS3 Moderno:** Construir layouts com **Flexbox** e/ou **CSS Grid**.
- 📱 **Responsividade:** Garantir adaptação visual para diferentes tamanhos de tela (abordagem *Desktop-First*).

## 📈 Histórico de Desenvolvimento

O projeto foi iniciado após a introdução dos conceitos em aula e está sendo **reconstruído do zero de forma individual**:

1. **Análise do Figma:** Mapeamento dos componentes e tokens de design (cores e fontes).
2. **Estruturação HTML:** Construção do esqueleto da página com marcas semânticas.
3. **Estilização Desktop:** Construção do layout principal para telas grandes.
4. **Ajustes de Responsividade:** Implementação de Media Queries para telas menores.
5. **Deploy:** Publicação oficial no GitHub Pages.
